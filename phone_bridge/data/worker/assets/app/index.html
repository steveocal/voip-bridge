Download the app

On a computer? Scan this with your Android phone's camera to open this page there, then tap Download the app.

Installing

  1. Tap Download the app. If Chrome warns the file might be harmful, tap Download anyway.
  2. When it's finished, tap Open (or open voip-bridge.apk from your notifications or Downloads).
  3. If Android says Chrome isn't allowed to install apps, tap Settings, turn on Allow from this source, then go back.
  4. Tap Install. On Xiaomi/Redmi phones a security scan may run first; wait for it, then tap Install or Continue.

Already have an older VoIP Bridge?

If it says App not installed or that the package conflicts with an existing package, uninstall the old VoIP Bridge first (press and hold its icon, then Uninstall), and install again. You only need to do this once. After that, updates install over the top.

After installing

  1. Open VoIP Bridge and allow the microphone and notifications.
  2. So calls can ring when the phone is locked: Settings → Apps → VoIP Bridge → allow full-screen notifications, and set Battery to Unrestricted.
  3. In the app's Settings, enter your extension and password.
